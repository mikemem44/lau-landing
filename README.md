## Laura Zambrano - Art Portfolio

Personal art portfolio website for Laura Zambrano, a visual artist from Managua. Features a curated gallery of artwork, artist biography, and a contact form for commissions and collaborations.

**Live demo: [https://lau-landing-eta.vercel.app](https://lau-landing-eta.vercel.app)**

### Features
- Responsive gallery with images served from Cloudflare R2
- Contact form with Zod validation and Web3Forms integration
- Dark theme with custom design tokens and typography
- Mobile-first responsive layout

### Tech Stack
- Framework: Next.js 16 (App Router) + React 19
- Styling: Tailwind CSS v4
- Type Safety: TypeScript
- UI Components: Radix UI (Dialog, Accordion)
- Forms: React Hook Form + Zod
- Icons: Lucide React
- Fonts: Inter, Playfair Display, JetBrains Mono
- Storage: Cloudflare R2 + Cloudflare Workers
- Email: Web3Forms
- Deployment: Vercel
